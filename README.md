# 時間記録

9種類の行動ボタンを切り替えるだけで、一日の時間を記録する個人用Webアプリです。Pixel 9aのChromeを想定したスマートフォン対応のPWAです。外部サービス・ログイン・有料API・ビルド作業は不要です。

## GitHub Pagesで使う

1. ZIPを展開し、`time-record` フォルダー内のファイルをGitHubリポジトリの直下にアップロードしてください。`index.html` がリポジトリ直下にある構成にします。`tests` フォルダーはテスト用なので公開に必須ではありません。
2. GitHubリポジトリの Settings → Pages でブランチからの公開を選び、アップロード先ブランチのルート `/ (root)` を指定します。
3. 公開されたHTTPSのURLをPixel 9aのChromeで開きます。
4. 画面下の「使い方・データの管理」を開き、「オフライン準備完了」を確認します。
5. Chromeのメニューから「ホーム画面に追加」（環境によって「アプリをインストール」）を選びます。
6. 一度オンラインで準備を済ませれば、圏外でも使えます。初回アクセスには通信が必要です。

公開されるのはアプリのファイルです。行動記録はサーバーに送信されません。バックアップJSONはGitHubにアップロードしないでください。

## 使い方

- 「時間記録」で睡眠・身支度・家事・運動・仕事・勉強・遊び・食事・その他のいずれかを押します。配置は3×3です。
- 別の行動を押すと、それまでの記録が終了し、次の記録が即時に始まります。
- 同じ行動を再度押しても、開始時刻は変わりません。
- 画面を閉じたり端末を再起動しても、保存済みの開始時刻から経過時間を計算します。バックグラウンドで常時処理を実行する必要はありません。
- 「記録を停止」で、記録しない時間を作れます。
- 「集計結果」→「日付を選ぶ」で年・月・日を上下に回し、「この日を見る」を押します。矢印でも前後の日に移動できます。
- 円グラフの比率は、その日に記録した時間を100%とした割合です。9項目すべての時間と、記録の時系列も確認できます。
- 記録はミリ秒で保持し、集計表示は分未満を切り捨てます。このため各項目の表示値の合計と合計欄に最大数分の差が出る場合があります。
- 日付の区切りは端末の現地時間の午前0時です。タイムゾーン変更時は現在の端末タイムゾーンで再集計します。

## データとバックアップ

localStorageに保存します。同一端末・同一ブラウザ・同一公開元で利用してください。ブラウザデータの削除、プライベートモード、端末紛失などで記録を失うことがあります。「バックアップ保存」でJSONを定期保存してください。復元は既存の全記録を置き換え、実行前に確認します。記録中のバックアップを復元すると、その開始時刻から記録が続きます。

端末間同期や押し忘れた記録の手動編集は含みません。時刻は端末の時計に依存するため、正しく設定してください。ストレージ書込み失敗時はエラーを表示し、切り替えを確定しません。

## PCで動作確認

Node.js 18以上で、このフォルダー内から以下を実行します。追加パッケージのインストールは不要です。

```sh
npm start
```

`http://127.0.0.1:4173` を開きます。終了は Ctrl+C。ファイルを直接開く方法ではオフライン機能を利用できないため、上記またはGitHub Pagesを使用してください。

```sh
npm test
```

記録切替、同一ボタン、停止、日付またぎ、継続記録、破損・重複データ、時計逆戻りのテストを実行します。

## ファイル構成

- index.html / style.css / app.js：画面と操作
- core.js：記録データの検証・切替・集計
- sw.js：オフライン用キャッシュ
- manifest.webmanifest / icon*：ホーム画面用情報・アイコン
- server.cjs / package.json：依存パッケージ不要のローカル確認用
- tests/core.test.cjs：記録・集計の自動テスト

更新時は `sw.js` のCACHE名末尾を `v2` などへ変更し、変更したファイル一式をアップロードしてください。オンラインで開いた後にアプリの全画面・タブを閉じ、再度開くと新しいキャッシュへ切り替わります。キャッシュ削除と行動記録の保存場所は別です。
